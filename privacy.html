Privacy policy

Last updated: 11 October 2026

comma-archiver uploader is a personal tool used only by its owner, on the owner's own computer, with the owner's own Google account.

What it accesses

With the owner's consent it uses the YouTube Data API to upload the owner's dashcam review videos to the owner's YouTube channel and to read the processing status of those videos. It does not read any other Google account data.

What it stores

The OAuth token and a list of uploaded video IDs are stored in local files on the owner's computer. Nothing is sent to any server other than Google's.

Sharing

No data is collected from anyone else, and no data is sold, shared or transferred to third parties. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions, and the local token file can be deleted.
